# Redes-Loteria
Este projeto tem como objetivo criar conhecimentos sobre o uso das bibliotecas de Sockets para desenvolvimento de 
aplicações em rede no modelo client/server e ainda utilizar conhecimentos em:
- Uso de plataformas de desenvolvimento
- Uso de threads
- Memória compartilhada
- Estrutura de Dados

### Como utilizar
1. em um terminal: ` cd server `
2. ` python3 loteria_server.py `
3. em outro terminal: ` cd client `
4. ` pyhon3 loteria_client.py`

| Command | Description |
| --- | --- |
| `cd server` | enter in the folder server|
| `python3 loteria_server.py` | run server file |
| `cd client` | enter in the folder client |
| `python3 loteria_client.py`| run client file |
